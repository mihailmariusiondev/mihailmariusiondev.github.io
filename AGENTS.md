# Portfolio

## Scope
- Public Astro/TypeScript portfolio: professional profile, verified career timeline, sanitized case studies, recommendations and English/Spanish CVs. `README.md` describes the product; content and CV sources stay in this repository.

## Working rules
- Preserve the privacy boundary: no client source, credentials, internal URLs, private screenshots, proprietary documentation or vulnerability details. Global personal context is not publishable portfolio content.
- Case studies describe verified completed work; do not invent projects, employment history or claims. Use the assigned Astro and web skills when their tasks apply; assignments are recorded by this repository's `.agents/skills` links.

## Commands and checks
- `npm install` installs the declared dependencies; use the existing lockfile workflow.
- `npm run dev` serves local development; `npm run build` runs Astro checks and builds `dist/`; `npm run preview` serves that build.
- For presentation changes, inspect the rendered affected pages and links. A successful build alone does not prove layout or accessibility. Publishing remains a separate authorized effect.

## Maintenance
- This repository's root `AGENTS.md` is the canonical local source; `CLAUDE.md` aliases it.
- Keep profile, career timeline, case studies and CV variants consistent with their verified professional owner. Update `README.md` when scope, stack or development commands change; never copy private source material as proof.
