# Portfolio design bake-off — 2026-09-15

Archived design material for the portfolio: 16 v1 concepts and 16 v2 concepts. This directory is
not the live site. No concept has been selected, integrated, or published from this archive.

## Preview an artifact

Each concept has a built `dist/` artifact. Serve one locally, for example:

```sh
python3 -m http.server 8080 --directory v2/s02-desktop-os/dist
```

Then open `http://localhost:8080`. The picker is at `gallery/index.html`.
